Nạp file Excel danh mục giá hoặc tải dữ liệu đã lưu từ Firebase để bắt đầu.

📥 Cập nhật chiết khấu hàng loạt

Upload file Excel có cột Tên sản phẩm và Chiết khấu KH (%). Hệ thống dò khớp thông minh dựa trên Tên, Mã hàng, Hàm lượng, Quy cách.

Click để chọn file Excel chiết khấu

File cần có: Tên sản phẩm · % Chiết khấu KH (các cột khác là tùy chọn)

💡 Mẹo dò khớp chính xác hơn:
Chọn thêm Mã hàng → khớp tuyệt đối (100%)
Chọn thêm Hàm lượng → phân biệt 20mg / 40mg / 80mg
Chọn thêm Quy cách → phân biệt cùng tên khác đóng gói
Hệ thống tự nhận dạng tên cột — không cần đặt tên chuẩn
✓ Nguồn (Excel) → Khớp với sản phẩm CK cũ → mới Độ tin cậy

🧮 Lọc dữ liệu & Xuất Excel

Lọc theo Cơ sở sản xuất (gợi ý cả tên gần giống) và khung tỉ lệ chiết khấu. Bấm Chọn tất cả rồi Xuất Excel đúng dữ liệu đã lọc.

Không chọn cơ sở nào = lấy tất cả cơ sở. Có thể thêm nhiều cơ sở cùng lúc.
